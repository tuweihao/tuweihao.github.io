## 为什么重建博客

之前的 `tuweihao.github.io` 只是跟着 GitHub 官方教程创建的一个静态页面：

> 你好，世界！这是我的第一个 GitHub 网页！

现在，它升级成了一个真正的博客 —— 基于 [Hugo](https://gohugo.io/) 静态网站生成器和 [Bear Neo](https://github.com/rokcso/hugo-bearneo) 主题搭建。

## 这个博客怎么运作

- **写作**：文章以 Markdown 格式存放在 `content/posts/` 目录下
- **构建**：推送到 GitHub 后，GitHub Actions 自动完成构建和部署
- **访问**：站点地址是 [tuweihao.github.io](https://tuweihao.github.io/)
